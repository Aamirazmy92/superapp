# hello-veyo

The example plugin for Veyo. Install it from **Plugins → Discover** after adding this folder's parent as a local marketplace.

It adds:

- **Say hello** and **Git summary** commands (Ctrl+K and Run command)
- a **Claude · Sonnet** agent preset
- a **review-diff** prompt and an **explain-file** skill
- the **everything** MCP server definition (added to Claude Code or Codex only when you choose to)
- the **Dusk** theme
